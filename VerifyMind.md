##### **VerifyMind**

**Интеллектуальный помощник для проверки учебных фактов в мессенджере MAX (экосистема Сферума).**



##### **Идея**

**Школьники тратят десятки минут на перепроверку учебной информации из интернета. VerifyMind мгновенно проверяет утверждения по учебникам и ФГОС, указывая конкретный источник — или честно говорит «Не уверен», если данных недостаточно.**



##### **Как работает**

**Ученик пишет вопрос боту в MAX**



**Бот отправляет запрос в DeepSeek с системным промптом: проверять только по учебникам и ФГОС, не выдумывать источники, честно отвечать «Не уверен» при недостатке данных**



**Модель возвращает JSON с пятью полями: вердикт (Верно/Неверно/Не уверен), объяснение (2-3 предложения), источник (учебник, параграф, стандарт), ошибки (перечень неточностей или «Ошибок не найдено»), главное (краткий вывод одним предложением)**



**Бот нормализует ответ к обязательному формату и отправляет ученику оформленный текст**



**Важно: модель может указывать приблизительные номера параграфов. Всегда сверяйте с актуальными учебниками. Бот честно сообщает «Не уверен», если не может дать однозначный ответ.**



##### **Пример работы**

**Вопрос: «Столица России — Москва»**



**Ответ бота:**



**ВЕРДИКТ: Верно**



**ОБЪЯСНЕНИЕ: Москва является столицей РФ согласно Конституции.**



**ИСТОЧНИК: Конституция РФ, ст. 1; учебник «География России», 8 класс**



**ОШИБКИ: Ошибок не найдено**



**ГЛАВНОЕ: Москва — официальная столица России**



##### **Структура проекта**

**main.py — ядро: check\_fact() проверяет непустой ввод, выбирает режим (реальный запрос или заглушка без ключа), отправляет запрос в DeepSeek через OpenAI-клиент, парсит JSON, нормализует и форматирует ответ**



**bot.py — бот для MAX на Long Polling: get\_updates() опрашивает сервер, send\_message() отправляет ответ, main\_loop() обрабатывает сообщения, ловит ошибки и не падает**



**server.py — веб-сервер FastAPI для webhook-режима (опционально): GET / для проверки живости, POST /webhook для приёма сообщений**



**max\_subscribe.py — подписка на webhook (опционально): отправляет POST на сервер MAX с публичным адресом и типом обновлений**



##### **Переменные .env**

**DEEPSEEK\_API\_KEY — ключ API DeepSeek (обязательно)**



**DEEPSEEK\_MODEL — модель (по умолчанию deepseek-chat)**



**MAX\_BOT\_TOKEN — токен бота в MAX (обязательно для bot.py)**



**WEBHOOK\_URL — публичный адрес (только для server.py/max\_subscribe.py, опционально)**



##### **Запуск (локально, без хостингов)**

**Создайте виртуальное окружение:**



**python -m venv venv**

**source venv/bin/activate (Linux/Mac)**

**venv\\Scripts\\activate (Windows)**



**Установите зависимости:**



**pip install -r requirements.txt**



**Создайте .env и заполните переменные**



**Запустите бота в MAX (Long Polling):**



**python bot.py**



**Для проверки без мессенджера:**



**python main.py**
